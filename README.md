# Server dotfiles

Окружение для удалённого Ubuntu-сервера: Zsh, tmux, Neovim, Yazi, bat,
btop и lazygit. В утилитах используется фиксированная **Catppuccin Frappé**;
Zsh использует стандартные цвета Oh My Zsh и плагинов. Файлы разворачиваются через GNU Stow.

## Установка

От root установите инструменты для запуска установки и клонирования:

```sh
apt-get update
apt-get install -y make git python3 ca-certificates
```

От обычного пользователя клонируйте репозиторий сразу в `~/.dotfiles`:

```sh
git clone https://github.com/Nemagu/server_dotfiles.git "$HOME/.dotfiles"
cd "$HOME/.dotfiles"
```

Каталог `~/.dotfiles` должен отсутствовать или быть пустым. Установите системные
утилиты от root, затем выполните пользовательскую настройку:

```sh
sudo make system
make install
make shell
```

Если sudo недоступен, root может запустить `make system` из того же каталога
репозитория. Остальные команды выполняются от обычного пользователя.
`make shell` может запросить его пароль; новая оболочка применяется при
следующем входе по SSH.

Системный установщик поддерживает Ubuntu x86_64 и arm64. Он устанавливает
зависимости через apt, а актуальные Neovim, Yazi/ya, lazygit, fzf и Node.js LTS
скачивает из официальных релизов. Runtime Neovim и Node.js находится в `/opt`,
команды — в `/usr/local/bin`. Повторный запуск устанавливает актуальные версии
перечисленных компонентов, без полного обновления ОС. Если apt занят
автоматическим обновлением, установка пакетов ждёт освобождения блокировки
до 10 минут; затем при необходимости команду можно повторить.

Скрипты в `scripts/` исключены из Stow. Все установочные скрипты используют только
стандартную библиотеку системного `python3`, без venv и сторонних пакетов.
Для установки нужен доступ к сети. При конфликтах Stow остановится:
сохраните старые конфиги отдельно и повторите `make install`.

## Команды Make

Подробное описание каждой команды, прав и зависимостей: `make help`.

| Команда | Назначение |
| --- | --- |
| `make` / `make help` | Показать команды |
| `make system` | Установить системные утилиты Ubuntu, от root |
| `make system-update` | Обновить те же системные утилиты, от root |
| `make install` | Установить пользовательские инструменты, плагины и ссылки |
| `make update` | Обновить пользовательские инструменты и плагины |
| `make rust` / `make cargo` | Установить Rust/Cargo, rust-analyzer, rust-src, rustfmt, Clippy |
| `make uv` | Установить uv, если он отсутствует |
| `make tools` | Установить basedpyright, Ruff, codebook и тему bat |
| `make link` | Проверить и применить ссылки Stow |
| `make plugins` | Установить плагины Zsh/tmux и тему Yazi |
| `make shell` | Сменить login shell текущего пользователя на Zsh |
| `make check` | Проверить команды, синтаксис Zsh и тему bat |

## Neovim и терминал

После установки откройте `nvim`: lazy.nvim установит плагины.
Недостающие языковые инструменты установите через `:Mason`;
проверка редактора — `:checkhealth`, обновление — `:Lazy` и `:Mason`.
Makefile не запускает Neovim для установки зависимостей.
basedpyright, Ruff и codebook устанавливает `make tools`, Rust — `make rust`.

Zsh использует стандартное приглашение Oh My Zsh `edvardm` без переопределения цветов.
Команды `y` и `yz` запускают Yazi и переходят в выбранный каталог после выхода.
В tmux префикс — `Ctrl-a`, `Ctrl-a r` перечитывает конфиг,
`Ctrl-a d` отсоединяет сессию. В локальном терминале настройте Frappé и
Nerd Font; серверные шрифты не задают отображение SSH-клиента.

## Обновление и проверки

```sh
cd "$HOME/.dotfiles"
git pull --ff-only
sudo make system-update
make update
make check
```

Обновление тем и плагинов может менять `yazi/package.toml` и `lazy-lock.json`;
перед коммитом проверьте `git diff`.
Скрипт смены shell требует, чтобы Zsh был указан в `/etc/shells`;
пакет Ubuntu регистрирует его при установке.

Для проверки установщиков без загрузок и изменения системы:

```sh
python3 -m unittest discover -s scripts -p 'test_*.py'
```
