Запускайте make из корня репозитория. Системные цели требуют root,
остальные — обычного пользователя. Для загрузок нужен доступ к сети.

make / make help
  Показывает эту справку. Ничего не устанавливает.

make system                     [root, Ubuntu x86_64/arm64]
  Устанавливает apt-зависимости, Stow, Zsh, tmux, bat, btop и средства поиска.
  Скачивает актуальные Neovim, Yazi/ya, lazygit, fzf и Node.js LTS.
  Бинарники: /usr/local/bin; runtime Neovim/Node.js: /opt. Нужен python3.
  При блокировке dpkg ждёт до 10 минут, не прерывая чужие обновления.

make system-update              [root]
  Повторяет make system, обновляя перечисленные пакеты и бинарники.
  Полное обновление ОС и пользовательскую настройку не выполняет.

make install                    [пользователь, после make system]
  Последовательно выполняет rust, uv, tools, link, plugins, check.
  Устанавливает компоненты в HOME и создаёт ссылки конфигов через Stow.
  Не запускает Neovim и не меняет login shell; для смены есть make shell.

make update                     [пользователь]
  Обновляет stable Rust, пользовательский uv, basedpyright и Ruff.
  Обновляет codebook, если он установлен через Cargo.
  Обновляет Git-плагины через pull --ff-only и зависимости Yazi, применяет Stow.
  Затем проверяет окружение. Системные пакеты и сам репозиторий не обновляет.
  Плагины Neovim обновляются в редакторе через :Lazy и :Mason.

make rust / make cargo          [пользователь]
  Устанавливает rustup при отсутствии и minimal stable Rust toolchain.
  Добавляет rust-analyzer, rust-src, rustfmt и Clippy. Нужен доступ к сети.
  Существующий rustup используется повторно; cargo — алиас цели rust.

make uv                         [пользователь]
  Устанавливает uv официальным установщиком, если команда отсутствует.
  Уже установленный uv не переустанавливает. Конфиги оболочки не изменяет.

make tools                      [пользователь, после rust и uv]
  Устанавливает basedpyright и Ruff через uv tool install.
  При отсутствии устанавливает codebook-lsp через Cargo и Frappé для bat.
  Требуются uv, cargo и bat. Виртуальное окружение для скриптов не нужно.

make link                       [пользователь, нужен Stow]
  Сначала проверяет конфликты, затем применяет ссылки в HOME через --restow.
  Не использует --adopt; конфликты нужно разрешить вручную после резервного копирования.
  Makefile, scripts и внешние репозитории исключены из развёртывания.

make plugins                    [пользователь, после link; нужны Git и ya]
  Клонирует Oh My Zsh, fzf-tab, autosuggestions, syntax-highlighting,
  history-substring-search, TPM и tmux-sensible, если каталогов ещё нет.
  Устанавливает зависимости Yazi из package.toml; существующие Git-плагины
  не обновляет — для этого используйте make update.

make shell                      [пользователь, после проверки Zsh]
  Меняет login shell своей учётной записи на Zsh через chsh.
  Может запросить пароль. Путь Zsh должен присутствовать в /etc/shells.
  Применяется при следующем входе. Не входит в make install.

make check                      [пользователь]
  Проверяет команды в PATH, синтаксис конфигов Zsh и наличие Frappé в bat.
  Ничего не устанавливает. При недостающих компонентах возвращает ошибку.
